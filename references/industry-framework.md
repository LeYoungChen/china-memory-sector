# 中国存储芯片板块 — 分析框架

## 1. 板块驱动逻辑
存储是类大宗、由产能驱动的周期行业。A 股存储公司大多是**价格接受者**，位于三星 / SK 海力士 /
美光 / 铠侠 / 西部数据（闪迪）以及未上市的国内 IDM（长鑫存储 CXMT：DRAM；长江存储 YMTC：NAND）下游。

周期传导链（领先 → 滞后）：
1. 云厂商 / AI 资本开支 → HBM 与服务器 DRAM 需求 → 晶圆产能从通用 DRAM/NAND 被挤出
2. 原厂资本开支纪律 + 原厂库存周数
3. **合约价**（DRAMeXchange / TrendForce 集邦、CFM 闪存市场）—— 最核心的单一变量
4. 模组厂库存收益/损失（低买高卖：毛利率滞后价格约 1–2 个季度）
5. 利基存储（NOR / SLC NAND / DDR4 / EEPROM）滞后跟涨，原厂退出旧制程（如 DDR4 停产）会放大涨幅

## 2. 细分板块及盈利来源

| 细分 | 公司 | 盈利驱动 | 周期敏感度 |
|---|---|---|---|
| 存储设计（利基存储 Fabless） | 兆易创新、北京君正、普冉股份、东芯股份、聚辰股份 | NOR / 利基 DRAM / SLC NAND 单价；代工成本 | 高，滞后于通用存储 |
| 接口与主控 | 澜起科技、联芸科技 | DDR5/服务器渗透率、单条内存价值量、SSD 主控份额 | 中；成长性 > 周期性 |
| 模组与存储 | 江波龙、佰维存储、德明利、朗科科技 | 采购成本与售价的价差；库存 | 极高；库存收益杠杆 |
| 分销 | 香农芯创 | 海力士产品出货量 × 低毛利 | 中；量驱动 |

## 3. 核心指标及解读
- **单季毛利率**——方向比水平更重要。涨价期模组厂毛利率因库存收益飙升，跌价期因减值暴跌。
- **存货周转天数**——天数上升 + 价格上涨 = 主动囤货（涨价期利好，拐点处危险）；天数上升 + 价格下跌 = 风险。
- **单季营收同比**——价 × 量；与合约价变化对照。
- **市净率（PB）及 3 年分位**——周期股首要估值锚。盈利顶部 PE 最低、底部 PE 最高甚至为负（"高 PE 买、低 PE 卖"）。
- **PE(TTM)**——可用，但若 TTM 利润含大额库存收益需提示；非经常性损益大时用扣非 PE。
- **PS**——适用于周期底部亏损的模组厂。

## 4. 中国市场特有因素
- 国产替代：长鑫/长江存储扩产节奏及采购政策。
- 美国出口管制（实体清单、HBM/先进 DRAM 限制）——限制长鑫/长江设备获取，同时强化国产采购偏好。
- 长鑫等国内 IDM 的上市进程——大体量新股可能带来重估或分流资金。
- 交易制度：科创板/创业板 ±20% 涨跌幅 vs 主板 ±10%；散户驱动的动量；北向资金。

## 5. 常见板块争议
- 本轮上行周期能持续多久？（三大原厂资本开支反应；AI 需求持续性）
- 模组厂盈利是"真实"的还是会回吐的库存收益？
- 长鑫/长江扩产是利好（供应链安全）还是利空（利基 DRAM/NAND 价格压力）？
- 接口芯片：澜起是否已对 DDR5 / MRCD / CXL 预期定价充分？

## 6. 数据核查陷阱
- 每股净资产增幅远超当年留存收益（增发、H 股上市、其他综合收益公允价值变动）→ PB 分位会机械性下移，不能据此称"便宜"。
- 扣非与归母净利润差距大（如投资收益、政府补助）→ 用扣非 PE。
- 单季数据由累计数倒推；新上市公司进入样本会改变口径。
